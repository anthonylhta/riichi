# Riichi

A browser-based riichi mahjong game built for players who want to understand the game, not just play it.

## Features

- Full riichi mahjong ruleset (yaku, scoring, furiten)
- Three CPU opponents with distinct difficulty levels
- Post-game analysis highlighting key decision points
- In-game hint system to help you learn the lines
- Daily puzzle to sharpen your reading

## Tech Stack

- [SvelteKit](https://kit.svelte.dev/) — frontend framework
- [Neon](https://neon.tech/) — serverless Postgres
- [Vercel](https://vercel.com/) — hosting

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Development

```bash
npm run dev        # start dev server
npm run build      # production build
npm run check      # type checking
npm run lint       # lint
```
